# 截图补充指南 / Screenshot Guide

手册中所有待补截图的位置都以如下占位行标注（中文页 `📷 截图待补`，英文页 `📷 Screenshot TODO`）：

> 📷 截图待补：描述。放图后替换为 `![alt](相对路径)`

## 规范

- **路径**：中文界面截图放 `docs/image/cn/<页面路径>/<页名>-NN.png`，英文界面放 `docs/image/en/…`，与页面路径同构（占位行中已给出完整相对路径，放图后直接把整行替换为给出的 `![…](…)` 语句即可）；
- **命名**：小写连字符 + 两位序号，如 `window-01.png`、`document-03.png`；
- **格式与尺寸**：PNG；宽度建议 1200–1600px（弹窗可按实际）；需要标注的用红框标注关键控件；
- **语言**：界面截图跟随所在语言的手册（cn 页配中文界面、en 页配英文界面），两边可分开截取；
- **查找全部待补位置**：`grep -rn "📷" docs/cn docs/en --include="*.md"`。
