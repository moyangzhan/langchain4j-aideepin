# Quick Start

> [← User Guide](index.md) · [简体中文](../../cn/guide/quick-start.md)

This page walks the shortest path: **sign up & activate → get to know the UI → first conversation**. Model platforms are pre-configured by the admin, so regular users can start right away.

## 1. Sign Up & Activate

1. Open the AIDeepIn site, click **Login** at the bottom-left, and switch to the **Register** tab.
2. Enter your email, password (min. 6 characters), confirm it, and type the captcha (click the image to refresh).
3. The system sends an activation email — check your inbox (and spam folder).
4. Click the activation link in the email. The result page shows **activation successful** and returns to the home page within 5 seconds.

You can then log in with your email and password. For details (password reset, changing password), see [Sign-up, Login & Settings](account/account.md).

## 2. Get to Know the UI

After logging in, the global menu sits on the far left (icons only, hover for labels), top to bottom:

| Menu | Function |
|---|---|
| Chat | Talk to AI characters |
| Draw | Text to image |
| Gallery | Browse public images and your likes |
| Knowledge Base | Q&A grounded on knowledge bases |
| Apps | Create and run workflows |
| Tools | Enable MCP extensions |

At the bottom-left there are three more entries: **Prompt Store**, **Settings** (theme, language, quota, change password) and **Log out**.

## 3. First Conversation

1. Click **Chat**. New accounts get a default character automatically.
2. Pick a model in the selector above the input box:
   - Models are configured by the admin and shown as "platform avatar + model name";
   - A greyed-out model is currently unavailable — just pick another;
   - The selection is **global**: drawing and knowledge base Q&A follow it too.
3. Type a question and press Enter or click send.
4. The answer streams in. You can click **Stop** anytime.

### Try these next

- **Deep thinking**: toggle it on to see the reasoning process before the answer (some reasoner models can't turn it off).
- **Web search**: answers reference search results.
- **Upload an image**: with a vision (multimodal) model selected, upload a PNG/JPG (≤ 4MB) for recognition.
- **Switch characters**: click **New Character** above the character list, or create one from 11 **preset** categories.
- **Voice**: click the mic icon to record; the audio is transcribed and sent.
