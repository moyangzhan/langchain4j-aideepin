# Characters & Presets

> [← User Guide](../index.md) · [简体中文](../../../cn/guide/chat/character.md)

In AIDeepIn, **a conversation is a character**: each character has its own persona, linked resources and history. Click a character in the left list to switch; hover an entry for the **edit** pencil icon.

> Each account can create up to 50 characters.

## Creating a Character

Click **New Character** above the list. The dialog has two tabs: **New Character** and **Presets**.

Fill in the form on the **New Character** tab (field details in [Character Settings](character-config.md)) and save.

## Creating from Presets

The **Presets** tab offers ready-made characters by scenario: Tech/Engineering, Content/Creative, Education/Academic, Business/Management, Professional Services, Design/Image, Marketing, Customer Service, Admin/Office, Reporting Assistant, Others.

1. Expand a category and view an item's **persona**;
2. Click **Use** — the preset is copied as your own character ("Created successfully");
3. Used presets are marked **Used** and can be reused.

> Presets tagged **with knowledge base** automatically create a dedicated knowledge base with the same name when copied — no manual setup needed.

## Editing & Deleting

- Hover a list entry and click the pencil icon to open the edit form;
- The **Delete** button at the bottom of the form removes the character (confirmation: "Delete character {name}?"), along with its history.
