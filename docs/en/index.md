# AIDeepIn Documentation

AIDeepIn is an AI-assistant platform offering chat, knowledge base (RAG), workflows, image generation and an open API. The documentation has three sections:

## User Guide

[User Guide](guide/index.md) — For end users: the complete manual, from sign-up to chat, drawing, knowledge bases, workflows, tools and the admin console.

## API Reference

[API Reference](api/index.md) — For integrators: the open API (`/ext/v1`) covering character chat, knowledge base Q&A, draw tasks, MCP services and workflow runs.

## Developer Docs

[Developer Docs](dev/index.md) — For developers and operators: system architecture and model platform integration guides (chat / image / TTS / ASR).
