# 提示词商店

> [← 使用指南](index.md) · [English](../../en/guide/prompt-store.md)

点击左侧菜单底部的**提示词商店**图标（悬浮提示「提示词商店」）打开弹窗，集中管理常用提示词，便于在对话中快速复用。两个页签：

| 页签 | 内容 |
|---|---|
| 本地 | 你自己保存的提示词 |
| 在线 | 系统提供的在线提示词库 |

## 管理提示词

- **新增**：录入标题与提示词内容；标题或内容重复时会提示（「标题重复，请重新输入」「内容重复：{msg}，请重新输入」）；
- **编辑 / 删除**：维护已有条目；
- **搜索**：按关键词过滤。

## 导入与导出

| 操作 | 说明 |
|---|---|
| 本地导入 | 在导入弹窗粘贴提示词 JSON 批量导入；格式错误时提示「JSON 格式错误，请检查 JSON 格式」 |
| 在线导入 | 从在线库导入条目到本地 |
| 导出 | 将本地提示词导出为 `export_prompts.json` 备份或迁移 |

导入的 JSON 格式示例：

```json
[
  {
    "act": "充当英语翻译和改进者",
    "prompt": "我希望你能担任英语翻译、拼写校对和修辞改进的角色。"
  }
]
```

> [!TIP]
> 提示词 JSON 与流行提示词集合（如 awesome-chatgpt-prompts 的中文化项目）格式兼容，可直接复用社区整理的提示词库。
