# 提示词商店

> [← 使用指南](../index.md) · [English](../../en/guide/prompt-store.md)

点击左侧菜单底部的**提示词商店**图标打开弹窗，集中管理常用提示词，便于在对话中快速复用。两个页签：

| 页签 | 内容 |
|---|---|
| 本地 | 你自己保存的提示词 |
| 在线 | 系统提供的在线提示词库 |

## 管理提示词

- **新增**：录入标题与提示词内容；
- **编辑 / 删除**：维护已有条目；
- **搜索**：按关键词过滤。

## 导入与导出

| 操作 | 说明 |
|---|---|
| 本地导入 | 粘贴提示词 JSON 批量导入 |
| 在线导入 | 从在线库导入条目到本地 |
| 导出 | 将本地提示词导出为 `export_prompts.json` 备份或迁移 |
