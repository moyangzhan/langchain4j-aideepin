# 知识库问答

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/kb-qa.md)

点击左侧菜单**知识库**进入问答界面：左侧是知识库列表，右侧是问答区。这是直接「对知识库提问」的入口；也可以把知识库[关联到角色](../chat/character-config.md#关联知识库)后在对话中使用。

## 选择知识库

侧栏两个页签：

| 页签 | 内容 |
|---|---|
| 我的 | 我创建的知识库（含私有） |
| 公开 | 全站公开知识库（云端图标 = 公开，锁形图标 = 私有） |

点击条目右上角的 **i** 按钮查看知识库详情：文档数、向量数、公开属性、严格 / 宽松模式说明、最大召回数量、最小召回分数，以及**清除历史记录**（清空当前知识库的问答记录）。

侧栏底部的**知识库管理**按钮跳转[我的知识库](manage.md)进行建库与维护。

## 提问

1. 在顶部模型选择器中挑选回答模型；
2. 输入问题发送，回答流式输出；
   - **严格模式**下检索不到相关内容时直接返回「[无答案]」；
3. 生成中可**停止请求**；
4. 向上滚动分页加载历史问答（「暂无问答记录」表示还没有记录）。

## 引用溯源

回答下方：

- **引用**：命中的知识库片段，按文档分段模式展示（问答 → 命中问题+答案；父子 → 命中子块+父段；通用 → 段文本）；
- **图谱**：本次回答参考的[知识图谱](graph.md)片段。

## 删除问答记录

删除某条问答记录需二次确认（「提问及对应的答案会一起删除，继续执行？」）。

## API

顶栏**更多 → API** 可生成该知识库的 API Key 并查看接口文档，把知识库问答接入你自己的程序，详见 [API 参考 · 知识库问答](../../api/knowledge-base.md)。
