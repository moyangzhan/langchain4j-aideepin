# 知识库问答

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/kb-qa.md)

点击左侧菜单**知识库**进入问答界面：左侧是知识库列表，右侧是问答区。这是直接「对知识库提问」的入口；也可以把知识库[关联到角色](../chat/character-config.md#关联知识库)后在对话中使用（后者可叠加角色设定与记忆）。

> 📷 截图待补：知识库问答页（侧栏列表 + 问答区）。放图后替换为 `![知识库问答](../../../image/cn/guide/knowledge-base/kb-qa-01.png)`

## 选择知识库

侧栏两个页签：

| 页签 | 内容 |
|---|---|
| 我的 | 我创建的知识库（含私有） |
| 公开 | 全站公开知识库 |

- 图标含义：云端 = 公开，锁形 = 私有；
- 点击条目右上角的 **i** 按钮查看知识库详情弹窗，各标签的问号提示原文：

| 标签 | 提示原文 |
|---|---|
| 公开 / 私有 | 公开：所有人可见并使用；私有：仅创建者可见并使用。 |
| 严格模式 / 宽松模式 | 严格模式：严格匹配知识库，知识库中如无搜索结果，直接返回无答案；宽松模式：知识库中如无搜索结果，则将用户提问传给LLM继续请求答案。 |
| 最大招回数量：N | 向量搜索时，召回的文档数量不能超过该值 |
| 最小招回分数：N | 向量搜索时，召回的向量分数需大于该值 |

  弹窗中还展示文档数、向量数，以及**清除历史记录**按钮（确认提示「删除后不可恢复，请谨慎操作」）。

侧栏底部的**知识库管理**按钮跳转[我的知识库](manage.md)进行建库与维护。

## 提问

1. 在顶部模型选择器中挑选回答模型；
2. 输入问题，回车或点击发送；
3. 回答流式输出；生成中可点击**停止请求**；
4. 向上滚动分页加载历史问答（「暂无问答记录」表示还没有记录）。

> [!TIP]
> 提问技巧：知识库问答的效果取决于检索命中——用与文档原文接近的措辞提问、一次只问一个问题、必要时补充限定词（年份、产品名、部门）。

> [!NOTE]
> **严格模式**下检索不到相关内容时直接返回「[无答案]」，这是符合预期的行为（保证不编造）；需要自由发挥的回答请切换宽松模式（见[创建与设置知识库](manage.md)）。

## 引用溯源

回答下方：

- **引用**：命中的知识库片段，按文档分段模式展示：

| 分段模式 | 展示内容 |
|---|---|
| 问答 | 命中的问题 + 答案 |
| 父子分段 | 命中的子块 + 其父段 |
| 通用分段 | 段文本 |

- **图谱**：本次回答参考的[知识图谱](graph.md)片段。

## 删除问答记录

1. 悬浮要删除的问答记录，点击删除；
2. 二次确认（「提问及对应的答案会一起删除，继续执行？」）。

批量清理用知识库详情弹窗的**清除历史记录**。

## API

顶栏**更多 → API** 可生成该知识库的 API Key 并查看接口文档，把知识库问答接入你自己的程序，详见 [API 参考 · 知识库问答](../../api/knowledge-base.md)。
