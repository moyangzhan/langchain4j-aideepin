# 知识图谱

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/graph.md)

知识图谱索引从文档中抽取**实体（节点）**与**关系（边）**，与向量索引互补：向量按语义相似度召回，图谱按实体关系组织，适合多跳关联类问题。

## 生成图谱

图谱以**文档**为单位抽取，消耗知识库[入库模型](manage.md#3-文档索引设置模型)的 Token。三个入口：

1. 导入文档时在[索引弹窗](document.md#建立索引)勾选「图谱化」；
2. 文档列表操作列的**图谱**按钮（未图谱化时禁用）；
3. [分段管理](segment.md)页文档卡片上的「点击生成图谱」。

确认提示会注明所用的入库模型，例如「将使用当前知识库的入库模型「{model}」抽取知识图谱…确认开始?」。抽取为后台任务，期间图谱状态显示**图谱抽取中**，完成后自动刷新。

## 查看图谱

在文档列表或分段管理页点击**查看图谱**进入图谱页面：

- 画布展示节点与关系；
- 大图分页加载：底部显示「节点 {已加载}/{总数}，关系 {已加载}/{总数}」，点击**加载更多**继续；
- 图谱状态异常时页面给出提示（「图谱抽取中，完成后刷新查看」或「暂无图谱数据」）。

## 图谱在回答中的引用

对开启了图谱索引的知识库提问后，回答下方的**图谱**按钮可查看本次回答参考的图谱片段（引用图谱）；对话中关联知识库的角色同样支持。配合**引用**（命中片段）可以完整追溯回答依据，见[对话界面 · 记忆与引用](../chat/window.md#记忆与引用)。

## 维护提示

- 图谱**不会随正文修改自动更新**：切换分段模式或编辑正文后，需手动重新抽取；
- 停用片段会同时删除其图谱足迹，启用后如需图谱需重新抽取（见[分段管理 · 片段启停](segment.md#片段启停)）。
