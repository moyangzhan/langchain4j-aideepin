# 分段管理

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/segment.md)

从文档列表的**片段**操作进入片段（问答对）管理页。页面顶部是文档卡片：摘要、向量化状态、字符数、向量命中与时间；提供**查看正文**（只读，可跳编辑）、**查看附件**（文件预览）；未图谱化时显示「还未生成图谱，**点击生成图谱**」，已图谱化则显示**查看图谱**（见[知识图谱](graph.md)）。

页面按文档的分段模式展示三种列表之一。

## 通用分段列表

表格列：序号、文档片段（默认折叠 3 行，可展开）、命中次数、字符数、状态、操作。

| 操作 | 说明 |
|---|---|
| 编辑 | 修改片段文本，保存后自动重新向量化 |
| 停用 / 启用 | 见下文「片段启停」 |
| 删除 | 删除该片段及其向量 |

## 问答对列表

见 [Q&A 导入与生成](qa-import.md)：新增（一答案多问题）、文件导入追加、AI 生成 / 重新生成、编辑、停用 / 启用、删除。

## 父子分段列表

父段为最大切分单位，其下再切子块；检索时子块负责精准命中，返回其父段作为回答语境。

| 操作 | 说明 |
|---|---|
| 编辑父段 | 修改父段内容 |
| 停用 / 启用父段 | 同片段启停逻辑，作用于整个父段 |
| 删除父段 | **将删除该父段及其全部子块（含向量）** |
| 重新切分子块 | 删除该父段下全部子块及其向量，按父段当前内容重新切分；**手动添加或编辑过的子块会被覆盖** |
| 子块新增 / 编辑 / 删除 | 对单个子块的维护 |

## 片段启停

片段（及父段、问答对）可单独停用：

- **停用**：该片段不再参与检索，已生成的向量与图谱数据会被删除（确认提示：「将删除该片段已生成的向量（与图谱）数据」）；
- **启用**：重新生成向量与图谱（「图谱抽取会消耗模型额度」）。

## 向量修复与失败重试

- **向量缺失**：列表标记某片段向量缺失时，可点击**确认重建向量**修复；
- **索引失败**：页面底部的失败折叠面板列出各维度（向量化 / 图谱化）的最近失败原因，提供**重新向量化 / 重新图谱化 / 重新向量化和图谱化**三种重试；问答对列表为空时提供**AI 生成**入口；
- 重试执行中显示「索引执行中：{维度}」，页面每 3 秒自动轮询进度。
