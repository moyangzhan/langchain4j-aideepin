# 知识库概览

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/overview.md)

知识库（RAG）让你把自有资料交给 AI：文档导入后按规则切成**片段**并建立**索引**，提问时系统检索最相关的片段注入模型，使回答有据可依，并可在回答下方查看**引用**溯源。

适合的场景：企业制度问答、产品手册客服、个人笔记检索、领域知识助手。

## 整体动线

```
创建知识库 → 导入文档（选分段模式）→ 建立索引（向量化 / 图谱化）→ 问答或挂到角色
```

| 步骤 | 做什么 | 见 |
|---|---|---|
| 1. 建库 | 设置检索参数、切段策略 | [创建与设置知识库](manage.md) |
| 2. 导入 | 按表单录入或上传文件，选择分段模式 | [导入文档](document.md) |
| 3. 索引 | 向量化（必须）与图谱化（可选） | [导入文档](document.md#建立索引) |
| 4. 维护 | 片段启停、QA 维护、失败重试 | [分段管理](segment.md)、[Q&A 导入与生成](qa-import.md) |
| 5. 使用 | 知识库问答，或将知识库关联到角色 | [知识库问答](kb-qa.md)、[角色进阶设置](../chat/character-config.md) |

## 两个入口

- **知识库问答**：左侧菜单**知识库**，选择库后直接提问；
- **知识库管理**：问答页侧栏底部**知识库管理**按钮（或直接访问「我的知识库」页），完成建库、导入、维护。

## 三种分段模式

分段模式决定文档如何被切块与检索，是**文档级属性**——在导入文档或编辑文档时选择，同一知识库中可以混合存放不同模式的文档。

| 模式 | 适合内容 | 检索行为 |
|---|---|---|
| **通用分段** | 教材、手册、文章等连续文本 | 按建库的切段策略自动切块，按语义相似度召回 |
| **问答（Q&A）** | FAQ、客服问答等成对内容 | 问题与答案成对存储，命中任一问题即召回答案 |
| **父子分段** | 结构层次分明的长文档 | 小块（子块）用于精准命中，命中后返回其所在的**父段**（更大语境）给模型 |

如何选择：

- 资料天然是「一问一答」→ **问答**（准确率最高，但要整理成 Q&A 格式）；
- 连续成文、段落边界清晰 → **通用分段**（最省事）；
- 长文档、既要求命中精准又要求上下文完整 → **父子分段**（如产品说明书：子块命中参数条目，父段给出所在章节）。

> [!NOTE]
> 问答模式仅支持 XLSX / XLS / CSV 文件导入；父子模式可单独设置子块最大 Token 数（默认 200）。

## 两种索引类型

| 索引 | 作用 | 说明 |
|---|---|---|
| **向量索引** | 把片段转为向量，按语义相似度检索 | 文档可用的基础索引，问答的前提 |
| **图谱索引** | 从文档中抽取实体与关系，构建知识图谱 | 可选；抽取由大模型完成，**会消耗 Token** |

两种索引可同时建立，回答溯源时既可查看引用片段，也可查看引用图谱（见[知识图谱](graph.md)）。两者互补：向量擅长「语义相近」，图谱擅长「多跳关联」（A 的上级的负责人是谁）。

## 严格模式与宽松模式

知识库级的回答策略（建库时设置，详见[创建与设置知识库](manage.md)）：

- **严格模式**：检索不到相关内容时，直接返回「[无答案]」，绝不编造——适合制度、合规等要求答案必须有出处的场景；
- **宽松模式**：检索不到相关内容时，将问题交给大模型自由作答——适合容许发挥的助手场景。

## 公开与私有

- **私有**：仅创建者可见可用；
- **公开**：所有用户都能在问答入口的「公开」列表中看到并使用（只读，不能修改你的文档）。
