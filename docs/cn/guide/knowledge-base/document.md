# 导入文档

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/document.md)

从「我的知识库」点击**文档**进入知识库详情页（文档列表），工具条提供两种新增方式：

- **新增（按表单）**：直接录入标题、摘要与正文，适合少量内容；
- **新增（按文件）**：批量上传文件，适合正式导入。

## 按文件上传

点击**新增（按文件）**打开上传弹窗，步骤：

1. **选择分段模式**：通用分段 / 问答 / 父子分段（各带用途说明，详见[概览](overview.md#三种分段模式)）；
   - 问答模式仅支持 XLSX / XLS / CSV，可**下载模板**（表头 `question,answer`），每个文件生成一个独立的问答文档；
   - 父子模式可设置**子块最大 Token 数**（50–4000，默认 200）；
2. 拖拽或选择文件：支持 TXT、PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX，单文件 ≤ 10MB，一次最多 20 个；
3. 点击**上传并生成文档**。

上传完成后文档出现在列表中，初始向量化状态为**待处理**。

## 建立索引

选中文档后点击**索引选中内容（N 篇）**：

1. **选择索引类型**：向量化 / 图谱化（可同时勾选）；
   > 图谱化使用大模型抽取实体与关系，**会消耗一定量的 Token**。
2. 确认后提示「索引任务后台执行中」，列表自动轮询刷新状态。

索引状态也可在后续随时补建：图谱列操作在未图谱化时禁用，可从[分段管理](segment.md)页触发图谱抽取。

## 文档列表说明

| 列 | 说明 |
|---|---|
| 分段模式 | 通用分段 / 问答 / 父子分段 标签 |
| 向量化状态 | 待处理 / 处理中 / 已向量化 / 失败（附时间） |
| 图谱状态 | 是否已抽取图谱 |
| 附件 | 原始上传文件，点击预览 |
| 字符数 | 正文字符量 |
| 向量命中 / 图谱命中 | 该文档片段在检索中被命中的次数 |
| 已启用 | 开关。停用后该文档不参与检索（细节见[分段管理](segment.md#片段启停)） |

操作列：**片段**（进入分段管理）、**图谱**（查看图谱，未图谱化时禁用）、**编辑**、**删除**。

## 编辑文档

按表单新增或编辑文档时可设置：

- **标题 / 摘要 / 正文**；
- **分段模式**：切换时警告——「切换分段模式将作废该文档现有片段与向量索引，并按新模式自动重建；图谱不自动重建，需手动重新抽取」；
- 问答模式的附加项见[Q&A 导入与生成](qa-import.md)；
- 父子模式的**子块最大 Token 数**。

> 问答模式下直接编辑正文**不影响**已生成的问答对，需在问答对列表或通过 AI 重新生成来更新。
