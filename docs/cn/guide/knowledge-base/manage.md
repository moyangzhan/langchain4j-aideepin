# 创建与设置知识库

> [← 使用指南](../index.md) · [English](../../../en/guide/knowledge-base/manage.md)

进入**知识库 → 知识库管理**（或直接访问「我的知识库」页面），这里是知识库的总览：表格列出**标题（链接进详情）、描述、是否公开、是否严格**，操作列提供**文档 / API / 编辑 / 删除**。

## 新建知识库

点击**添加**进入建库表单，共五组设置：

### 1. 基本信息

| 字段 | 说明 |
|---|---|
| 标题（必填） | 知识库名称 |
| 描述 | 用途说明，公开后其他人也能看到 |
| 是否公开 | 公开：所有人可见可用；私有：仅创建者 |
| 严格模式 | 严格：检索不到直接返回无答案；宽松：转由大模型自由作答。详见[概览](overview.md#严格模式与宽松模式) |

### 2. 文档索引设置（向量）

| 字段 | 说明 |
|---|---|
| 文档切割时重叠数量 | 相邻片段重叠的字符量，提高边界信息保留（改动后**对新索引生效**） |
| 分段策略 | 递归分段 / 按段落 / 按行 / 按句 / 自定义分隔符（选自定义时必填分隔符） |
| 每段最大 Token 数 | 单个片段的上限 |
| Token 计数器 | OpenAI / 通义千问 / Huggingface 三种估算口径 |

### 3. 文档索引设置（模型）

**模型名称**：用于图谱抽取与 AI 生成问答对的大模型。图谱化和 QA 生成都消耗该模型的 Token。

### 4. 文档召回设置

| 字段 | 说明 |
|---|---|
| 文档召回最大数量 | 每次检索最多召回的片段数 |
| 文档召回最小分数 | 相似度低于该阈值的片段不参与回答 |

### 5. 大模型参数设置

| 字段 | 说明 |
|---|---|
| 系统提示词 | 知识库问答时的角色设定 |
| 创造性 / 随机性 | 回答温度（temperature） |

## 保存提示

若修改了**切段参数**（重叠、策略、最大 Token 等），保存时会提示：「切段参数变更将自动重建该知识库全部文档的向量索引，确定保存吗？」——确认后系统自动重建全部索引。

## 搜索与删除

- 顶部搜索框支持按标题过滤（回车或点击按钮触发），表格分页显示；
- **删除**需二次确认「删除后数据无法恢复，确定要删除知识库【{标题}】吗?」，删除后文档、片段、向量与图谱一并清除。
