# 应用与工作流

> [← 使用指南](../index.md) · [English](../../../en/guide/workflow/workflow.md)

左侧菜单的**应用**即工作流：通过可视化画布把多个处理节点编排成自动化 AI 流程（如翻译、FAQ 整理、多步内容生成），一次搭建、反复运行，也可通过 API 调用。

## 我的应用

- 侧栏分**我的 / 公开**两个页签；
- 点击列表项进入该应用的运行界面；悬浮条目出现编辑入口。

### 新建应用

1. 点击**新建应用**；
2. 填写表单：

| 字段 | 说明 |
|---|---|
| 节点 | 展示用名称 |
| 标题（必填） | 应用名，如：翻译 |
| 备注 | 用途说明 |
| 是否公开 | 公开后其他人可见可复制 |

3. 确定后进入应用页。

### 编辑 / 删除应用

编辑弹窗中的按钮：

| 按钮 | 说明 |
|---|---|
| 更新 | 保存对当前应用的修改 |
| 新增 | 另存为一个新应用 |
| 删除 | 删除前确认「输入与输出会一起删除，继续执行？」——运行历史一并删除 |

> [!NOTE]
> 非创建者打开公开应用时只有查看权限，保存按钮禁用并提示「只有工作流的创建者才能保存」。想改别人的应用：用更多菜单的**复制**生成自己的副本再编辑。

## 界面布局

顶栏：应用标题、**工作流 ↔ 请求列表**双视图切换（悬浮提示「切换到流程图 / 切换到请求列表」）、更多菜单（**编辑 / 查看**、**复制**、**API**）。

- **工作流视图**：画布编排区；
- **请求列表视图**：该应用的运行历史。

## 编辑工作流

1. 顶栏更多菜单点击**编辑**进入编辑态；
2. 从左侧**节点面板**把节点拖入画布（面板按组件列出全部可用节点）；
3. 连接节点形成流程；
4. 选中节点，在右侧**属性面板**编辑其配置（节点名称 + 组件功能说明 + 各参数）；
5. 顶栏**运行**在画布上试跑当前流程，**保存**持久化；**重新布局**整理节点位置；
6. 删除节点用节点自带的删除操作。

> [!WARNING]
> **开始节点只能有一个**——拖入第二个时系统会警告。开始节点是流程的唯一入口。

### 变量引用（提示词框通用规则）

带变量图标的输入框（提示词、查询内容、邮件标题等）支持引用变量，输入框上方有灰字提示：

1. 使用大括号引用【输入】中已定义变量，如：`{var_name1}`；
2. 使用 `{input}` 引用上个节点的默认执行结果。

### 可用节点（17 种）

#### 基础节点

| 节点 | 配置说明 |
|---|---|
| **开始** | 定义输入变量（**+新增变量**）：变量名、标题（显示名称）、类型（文本 / 数字 / 文件 / 布尔值）、是否必须、多选、最大文件数量（文件类型时）；另可设置开场白 |
| **结束** | 组装输出内容（支持变量引用），默认值「任务执行完成」 |
| **生成回答** | 调用 LLM 生成回复。提示词问号提示：**为空则表示使用上一个节点的输出做为提示词** |
| **人机交互** | 暂停流程等待用户输入；可设「输入前提示」，暂停时展示给用户 |

#### AI 能力节点

| 节点 | 配置说明 |
|---|---|
| **Agent** | 自主决策节点：选择角色；提示词（为空用上节点输出）；能力开关 **RAG / MCP 工具 / 联网搜索**（模型不支持联网时开关旁提示「模型不支持联网搜索功能」） |
| **OpenAI 画图** | 提示词（为空用上节点输出）、图像大小、图像质量、随机种子（附「随机生成」按钮） |
| **通义万相-画图** | 同上（DashScope 文生图） |
| **文档提取** | 从上传的文件中提取文本。开始节点没有文件类型输入时提示：「开始节点没有文件输入类型的参数，请添加后再操作」 |
| **关键词提取** | 选择模型 + 关键词数量 |
| **常见问题提取** | 选择模型 + 提取问题数量、国家和地区、语言 |
| **内容归类** | 选择模型 + 定义类别（分类 {n}：名称），为每个类别指定下一步节点 |

#### 知识节点

**知识检索**：检索选定知识库：

| 参数 | 说明 |
|---|---|
| 知识库 | 要检索的库 |
| 查询内容 | 支持变量引用 |
| 召回数量 | 滑块 |
| 命中最低分数 | 滑块 |
| 严格模式 | 问号提示原文：「严格模式：严格匹配知识库，知识库中如无搜索结果，直接返回无答案；宽松模式：知识库中如无搜索结果，则将用户提问传给LLM继续请求答案。」 |
| 默认回复内容 | 问号提示：「如果没有答案，则采用本内容」 |

#### 逻辑节点

**条件分支**：

- 每个分支条件组可选 **与 / 或**：
  - 与：提示「以上所有的条件都满足时跳转到下面的节点」；
  - 或：提示「以上任意一个条件满足即可跳转到下面的节点」；
- **保底情况**：提示「当以上 {count} 种分支情况都不匹配时，自动匹配本情况，跳转到下面指定的节点」；
- 至少保留一个条件、一个分支情况（删除时校验）。

**模板转换**：按模板拼装文本，可用 `{var}`、`{input}` 引用变量。

#### 集成节点

| 节点 | 配置说明 |
|---|---|
| **HTTP 请求** | 超时时间(秒)、重试次数、请求头（+添加请求头）、请求参数（+添加参数）、Content-Type；**清除 HTML** 问号提示：「如果响应是 HTML 格式且只需要主要内容，请将其打开。」；输出变量：`status_code`（Http 状态码）、`output`（响应体） |
| **邮件发送** | 发送人（系统 / 自定义）；自定义时配置 SMTP 服务器（如 smtp.exmail.qq.com）、SMTP 端口、发送人名称 / 邮箱 / 密码；接收人邮箱（必填，多个以逗号隔开）、抄送人邮箱、邮件标题（必填）、邮件内容（必填，支持变量引用） |
| **Google 搜索** | 查询内容（问号提示：为空则使用上一个节点的输出做为查询内容）、提取数量、国家和地区、语言 |

## 运行与请求列表

1. 画布**运行**或在应用页发起执行：填写开始节点定义的输入变量（文件支持 TXT、PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX，≤ 10MB）；
2. 执行产生一条**请求**记录；**请求列表**分页展示历史；
3. 点击查看**执行详情**：各节点的输入输出、文件预览（不支持内嵌预览的文件提供下载）；
4. 含**人机交互**节点的流程会暂停，显示「流程已暂停，等待用户输入中...」及节点配置的输入前提示；在输入框补充**文本**后继续执行（文件输入仅支持在流程开始的输入区）；
5. 请求记录可删除或清空（确认「输入与输出会一起删除，继续执行？」）。

> [!TIP]
> 调试新流程时先用小输入跑通全链路，再通过执行详情逐节点核对输入输出，定位问题节点。
