# 应用与工作流

> [← 使用指南](../index.md) · [English](../../../en/guide/workflow/workflow.md)

左侧菜单的**应用**即工作流：通过可视化画布把多个处理节点编排成自动化 AI 流程（如翻译、FAQ 整理、多步内容生成），一次搭建、反复运行，也可通过 API 调用。

## 我的应用

- 侧栏分**我的 / 公开**两个页签；点击**新建应用**，填写标题（必填）、备注、是否公开；
- 点击列表项进入该应用的运行界面；悬浮条目出现编辑入口；
- 编辑弹窗中可**更新**、**新增**（另存）、**删除**（「输入与输出会一起删除，继续执行？」）。

非创建者打开公开应用时只有查看权限——「只有工作流的创建者才能保存」。公开应用可通过更多菜单**复制**为自己的副本再编辑。

## 界面布局

顶栏：应用标题、**工作流 ↔ 请求列表**双视图切换、更多菜单（**编辑 / 查看**、**复制**、**API**）。

- **工作流视图**：画布编排区；
- **请求列表视图**：该应用的运行历史。

## 编辑工作流

进入编辑后：

- 左侧**节点面板**按分类列出可用节点，拖入画布；
- 选中节点后，右侧**属性面板**编辑其配置（节点名称、组件参数）；
- **开始节点只能有一个**——它是流程入口，配置输入变量与开场白；
- 顶栏**运行**在画布上试跑当前流程，**保存**持久化；**重新布局**可整理节点位置；
- 删除节点用节点上的删除操作。

### 可用节点（17 种）

| 类别 | 节点 | 作用 |
|---|---|---|
| 基础 | 开始 | 流程入口：定义输入变量（变量名 / 标题 / 类型[文本、数字、文件、布尔] / 必填 / 多选 / 最大文件数量）与开场白 |
| | 结束 | 流程出口，组装输出 |
| | 生成回答 | 调用 LLM 生成回复 |
| | 人机交互 | 暂停流程等待用户输入（可设输入前提示），后续在请求列表中续跑 |
| AI 能力 | OpenAI 画图 | 提示词 / 图像大小 / 图像质量 / 随机种子 |
| | 通义万相-画图 | DashScope 文生图 |
| | 文档提取 | 从上传的文件中提取文本 |
| | 关键词提取 | 从文本提取关键词（可设数量） |
| | 常见问题提取 | 提取 FAQ 对（提取问题数量、国家和地区、语言） |
| | 内容归类 | 按定义的类别对输入分类并路由下一步 |
| | Agent | 自主决策节点：设置角色、能力、工具、联网搜索 |
| 知识 | 知识检索 | 检索选定知识库（查询内容 / 召回数量 / 命中最低分数 / 默认回复内容） |
| 逻辑 | 条件分支 | 按与 / 或条件路由，附保底情况 |
| | 模板转换 | 按模板拼装文本，可引用变量 `{var}`、`{input}` |
| 集成 | HTTP 请求 | 调用外部 API：请求头、请求参数、超时、重试、清除 HTML、输出变量 |
| | 邮件发送 | SMTP 服务器 / 端口 / 发送人 / 接收人 / 抄送 / 标题 / 内容 |

## 运行与请求列表

- 画布**运行**或在应用页发起执行后，产生一条**请求**记录；
- **请求列表**分页展示历史请求，点击查看**执行详情**：各节点的输入输出、文件预览；
- 含**人机交互**节点的流程会暂停并显示「流程已暂停，等待用户输入中...」，补充输入（支持上传 TXT / PDF 等文件，≤ 10MB）后继续执行；
- 请求记录可删除或清空。

## API

更多菜单中的 **API** 可生成该应用的 API Key 与接口文档，通过 `POST /ext/v1/workflow/run` 从外部系统触发，详见 [API 参考 · 工作流](../../api/workflow.md)。
