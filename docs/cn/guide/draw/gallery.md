# 画廊

> [← 使用指南](../index.md) · [English](../../../en/guide/draw/gallery.md)

画廊汇集了全站**公开**的 AI 生成图片。进入画廊页面后，顶部可在两个视图间切换：

| 视图 | 内容 | 需要登录 |
|---|---|---|
| 公开图片 | 所有用户设为公开的绘图作品 | 否 |
| 我的点赞 | 你点赞过的图片 | 是 |

> 📷 截图待补：画廊页（公开图片网格视图）。放图后替换为 `![画廊](../../../image/cn/guide/draw/gallery-01.png)`

## 浏览

1. 顶部选择视图（公开图片 / 我的点赞）；
2. 网格布局滚动浏览，滚动到底自动加载更多；
3. 点击任意图片进入**绘图详情**。

## 互动

在绘图详情页可以：

| 互动 | 操作 | 说明 |
|---|---|---|
| 点赞 | 点击爱心图标 | 收藏该作品，可在「我的点赞」视图中回看；再次点击取消 |
| 评论 | 评论区输入框 | 在「这张图片如何？发表你的看法吧~」下发表评论；他人评论分页展示，可删除自己的评论 |
| 我也要画一张 | 详情按钮 | 带入该图的提示词，跳转绘画页再创作 |

> [!TIP]
> 将自己的作品设为公开的方法见[绘画 · 管理操作](draw.md#管理操作)——公开后其他用户就能在画廊中看到、点赞和评论你的作品。
