# 绘画

> [← 使用指南](../index.md) · [English](../../../en/guide/draw/draw.md)

进入**绘画**页面后，顶部可选择图片模型，中部为提示词编辑器（按所选模型平台切换形态），下方为**我的绘图记录**。

## 生成流程

1. 在顶部的图片模型选择器中挑选模型（不同平台对应不同编辑器）；
2. 填写提示词与参数，提交生成任务；
3. 任务异步执行，完成后图片出现在绘图记录中。

## 各平台编辑器参数

### OpenAI（gpt-image）

| 参数 | 可选值 |
|---|---|
| 图片尺寸 | 方形 1024x1024 / 竖屏 1024x1536 / 横屏 1536x1024 |
| 图片质量 | auto / low / medium / high |

### 通义万相（DashScope）

**文生图**：

| 参数 | 说明 |
|---|---|
| 图片尺寸 | 固定选项 |
| 图片数量 | 一次生成的张数 |
| 随机种子 | 指定种子可复现结果，勾选随机则每次不同 |

**背景生成**：为主图生成新背景，参数：

| 参数 | 说明 |
|---|---|
| 主图（必填） | PNG 格式，长边 ≤ 2048；图片中的 **RGBA 透明区域**即为待生成背景的区域 |
| 引导图（可选） | jpg / png / webp，用于约束背景风格 |
| 提示词 | 背景描述 |

> 背景生成依赖阿里云 OSS 的公网访问能力，若图片无法访问会导致任务失败，请阅读页面内的使用说明。

### SiliconFlow（硅基流动）

| 参数 | 说明 |
|---|---|
| 图片尺寸 | 从模型属性动态读取 |
| 随机种子 | -1 表示随机 |

## 我的绘图记录

- 列表按时间倒序，**无限上拉加载**，底部提示「没有更多了」。
- 点击记录进入**绘图详情**：查看提示词与引用图片（原图 / 引导图）、翻看评论、**我也要画一张**（带入提示词再创作）、**上一个 / 下一个**绘图记录导航。

### 管理操作

| 操作 | 说明 |
|---|---|
| 删除绘图任务 | 二选一：仅删除提示词，或删除该提示词及其生成的所有图片 |
| 删除单张图片 | 只删该图，保留提示词与其余图片 |
| 公开 / 私有切换 | 公开后图片进入画廊，所有人可见；关闭则恢复私有 |

## API

顶栏**更多 → API** 可生成绘图 API Key 并查看接口文档，把文生图接入你自己的程序，详见 [API 参考 · 绘图任务](../../api/draw.md)。
