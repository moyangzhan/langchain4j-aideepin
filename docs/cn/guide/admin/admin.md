# 管理端使用

> [← 使用指南](../index.md) · [English](../../../en/guide/admin/admin.md)

管理端（admin-web）面向系统管理员，与用户端（user-web）分开部署。使用管理员账号登录后可进行以下管理。

## 用户管理

- 搜索 / 查看用户详情；
- **新增用户**与**代为激活**（用户收不到激活邮件时的补救手段）；
- **冻结 / 解冻**账号、编辑用户资料。

## 模型平台与模型管理

这是管理员最常用的功能——普通用户「模型列表为空」或「模型不可用」多半要在这里解决：

| 操作 | 说明 |
|---|---|
| 模型平台管理 | 维护平台（OpenAI、DeepSeek、DashScope、SiliconFlow、Ollama 等）：**平台 API Key 就在这里配置** |
| 模型管理 | 添加 / 编辑 / 删除模型，控制 `is_enable` 启停 |
| 健康状态 | 查看各模型健康状态与原因，可手动**全量探测** |

接入全新平台的完整流程（数据库配置 + 按需开发）见开发文档[新模型平台接入指南](../../dev/model-platform-integration.md)。

## Token 监控

分页查询每一次 LLM 调用记录：用户、平台、模型、**输入 / 输出 Token**、耗时与时间，支持按用户、模型、平台、来源、时间区间过滤。

## 综合统计

仪表盘汇总：用户统计、知识库统计、Token 消耗统计、角色统计、图片消耗统计。

## 内容与资源管理

| 模块 | 说明 |
|---|---|
| 对话（角色）管理 | 查看与管理所有用户的角色 |
| 预设角色管理 | 维护用户端「预设角色」库 |
| 知识库管理 | 查看与管理全站知识库 |
| MCP 管理 | 登记 / 维护 MCP 服务与参数（用户端只能使用，不能自建） |
| 工作流管理 | 工作流搜索与启停 |
| 工作流组件管理 | 维护画布可用的节点组件 |

## 系统配置

键值化的系统配置，包括 **ASR / TTS 设置**（全局唯一的语音识别与合成服务，含模型、平台、时长与大小限制）、配额与速率限制等。修改后即时生效或按说明重启。
