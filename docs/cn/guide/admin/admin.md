# 管理端使用

> [← 使用指南](../index.md) · [English](../../../en/guide/admin/admin.md)

管理端（admin-web）面向系统管理员，与用户端（user-web）分开部署，使用管理员账号登录。共 13 个功能页面：主控台、用户管理、平台配置、模型管理、角色管理、预设角色管理、知识库管理、MCP 管理、流程编排（基础组件 + 流程列表）、Token 监控、系统设置（存储 / ASR / TTS / 额度 / 限流）。

## 主控台

六张统计卡片：**新增用户、新增知识库、新增文档、角色数、TOKEN 消耗、图片消耗**——每张显示「日」增量与总量 / 本月消耗。

## 用户管理

搜索过滤：名称、状态（待激活 / 正常 / 禁用）、创建 / 更新时间、是否管理员。

表格列：id、uuid、名称、邮箱、头像、状态（正常 / 待激活 / 已禁用）、激活时间、是否管理员等。

**新建用户**弹窗字段：

| 字段 | 说明 |
|---|---|
| 名称（必填）、密码 | 创建账号 |
| 每日 / 每月 token 配额 | Token 消耗上限 |
| 每日 / 每月请求配额 | LLM 请求次数上限 |
| 每日 / 每月图片配额 | 图片生成张数上限 |

行操作：**编辑**、**禁用 / 启用**（禁用即冻结，用户无法登录）。用户收不到激活邮件时，可将状态置为正常**代为激活**。

## 模型平台与模型管理

普通用户「模型列表为空」或「模型不可用」多半要在这里解决。

### 平台配置

表格列：名称、标题、接口地址(base_url)、API Key（已配置 / 未配置）、Secret Key、启用代理、兼容 OpenAI Api 格式。

新建 / 编辑字段：

| 字段 | 界面提示原文 |
|---|---|
| 名称 / 标题（必填）、接口地址、Api Key、Secret Key | 平台基础信息；内置平台选项：Openai、灵积、千帆、Ollama、深度求索、硅基流动 |
| 启用代理 | 表单说明：「详细的代理配置存放于项目代码的配置文件中」 |
| 是否兼容 OpenAI API | 表单说明：「兼容OpenAI API的平台，无需另外增加代码适配」——勾选后对话类模型零代码接入 |

> [!WARNING]
> 删除平台确认「删除后数据无法恢复，并且可能影响到模型调用…」；内置默认平台不提供删除。

### 模型管理

工具栏：新建、**刷新状态**（触发全量健康探测，提示「健康探测已触发」）。

表格列：名称、标题、类型、平台、是否启用、**健康状态**（🟢 正常 / 🔴 异常 / 禁用）、是否免费、上下文长度、最大输入 / 输出 token 数等。

新建 / 编辑关键字段：

| 字段 | 说明 |
|---|---|
| 类型（必填） | 文本 / 图像 / 嵌入 / 重排 / 文本转语音 / 语音识别 |
| 平台（必填） | 下拉取自平台配置 |
| 输入类型（必填，多选） | 文本 / 图像 / 音频 / 视频 |
| 输出格式（必填，多选） | 文本 / JSON |
| 是否推理模型 / 推理过程是否可以关闭 / 是否支持 web 搜索 | 对应[用户侧的能力开关](../model/model.md#能力差异) |
| 属性（properties） | JSON 编辑器，如 TTS 音色列表 `{"voices":[...]}`、图片尺寸列表 |
| 上下文长度、最大输入 / 输出 token 数 | 数值 |

行操作：**编辑、启用 / 禁用、设为免费 / 设为收费、删除**。

接入全新平台的完整流程（数据库配置 + 按需开发）见开发文档[新模型平台接入指南](../../dev/model-platform-integration.md)。

## 角色与预设角色管理

- **角色管理**：页面顶部提示「本系统中角色即AI角色」；查看所有用户的角色（标题、角色描述、消耗的总 token、是否开启上下文），可编辑 / 删除；
- **预设角色管理**：维护用户端「预设角色」库：标题、**角色类型**（11 类分类）、描述、角色设定、**知识库名称**（占位提示「留空则不自动创建知识库」——填写后用户复制该预设会自动创建同名专用知识库）。

## 知识库管理

搜索：标题、所属用户名称、是否公开、时间。

表格列：名称、所属用户、文档数、向量数、点赞数、是否公开，以及换行折叠的完整配置：重叠数量(文档切块时)、分段策略、每段最大Token数、模型(文档切块时)、文档召回最大数量、文档召回最小分数、大模型输出内容的创造性、请求时的系统提示词。

编辑弹窗与用户端建库表单一致（含**自定义分隔符**预设选项 `\n\n (段落)`、`\n (换行)`，可自定义输入）；仅编辑，无新建。

## MCP 管理

登记 / 维护 MCP 服务。编辑表单：

| 字段 | 界面提示原文 |
|---|---|
| 传输类型 | 网络传输(sse)（附警告标签「已过时」+ Alert：「SSE 已被 MCP 新规范弃用，新接入的服务建议使用 Streamable HTTP」）/ 流式传输(streamable-http) / 标准输入输出 |
| 安装类型 | docker / 本地 / 远程 / WebAssembly |
| SSE 地址、SSE 超时时间(秒)（默认 30）/ STDIO 命令、参数 | 按传输类型显示 |
| 参数设置 | 表格列：**参数名**（问号提示：「需要跟MCP Server中的参数名一致」）、**参数标题**（「标题只是用来展示，更好理解参数意义」）、值、**敏感信息**（「敏感信息会进行加密存储」）；底部「+新增参数」 |
| 参数定义 | 「参数定义（后续用户根据本定义填充实际的值）」——定义用户端配置弹窗中展示的参数表 |
| 网址、描述、是否启用 | — |

## 流程编排

- **基础组件**：维护画布节点组件。名称字段下方提示：「1. 名称是组件的唯一标识，保存后不可修改」「2. 仅限英文字母（a-z、A-Z），不能有空格」；排列顺序提示「组件在工作流设计器中的显示顺序，由小到大排列」；Start / End 组件不可禁用、不可删除；
- **流程列表**：全部工作流的标题、是否公开、是否启用、创建用户；可编辑 / 启停 / 删除。

## Token 监控

纯查询页。过滤：用户名、模型平台、模型名称、**来源类型**、请求时间区间。

表格列：用户名、来源类型、模型平台、模型名称、**输入 token、输出 token、耗时（ms）**、请求时间。

来源类型枚举：未知、角色对话、知识库问答、知识库索引、工作流节点、智能体、长期记忆提取、长期记忆分析——可据此定位额度消耗来源（知识库索引与记忆提取也消耗 Token）。

## 系统设置

| 页面 | 说明 |
|---|---|
| **存储配置** | 顶部显示当前存储位置（本地存储 / 阿里云OSS）。本地：「文件存储到服务器本地硬盘中」；OSS：填写 access key id / secret / bucket 名称 / endpoint 后保存并启用 |
| **ASR 语音识别** | 选择 asr 模型（平台自动联动）、最大识别时长(秒)、最大文件大小(KB) |
| **TTS 语音合成** | 顶部说明原文：「合成器位置：1. 客户端：表示使用客户端(如浏览器)的语音合成(TTS)功能，忽略【模型】、【平台】等参数，免费使用 2. 服务端：表示使用服务端的语音合成功能，实际上就是使用大语言模型如cosyvoice-v2…进行合成，通常需付费使用」；选择合成器位置 + tts 模型 |
| **额度配置** | 提示「**配置变更后10分钟内生效**」。四个维度：TOKEN 额度（每日 / 每月最多消耗）、请求额度（每日 / 每月最多请求数量）、图片额度（每日 / 每月生成数量）、聊天额度（每日最多提问数量 / 每月数量） |
| **限流策略** | 提示「配置变更后10分钟内生效」。文本请求与图片生成各设「请求数量 + 时间窗口（分钟）」 |
