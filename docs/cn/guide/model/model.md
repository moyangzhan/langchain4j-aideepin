# 模型选择与说明

> [← 使用指南](../index.md) · [English](../../../en/guide/model/model.md)

AIDeepIn 的模型由管理员统一配置（平台 API Key、模型启停均在管理端完成），普通用户只需在使用处**选择模型**。模型选择器**全局生效**：在对话、知识库问答、工作流中切换的是同一个全局选项。

## 在哪里选模型

| 场景 | 位置 |
|---|---|
| 文本模型（对话 / 知识库问答 / 工作流） | 对话输入栏、知识库问答页顶部的模型选择器 |
| 图片模型 | 绘画页顶部的图片模型选择器 |

选择器显示为「平台头像 + 模型名」。

## 模型类型

| 类型 | 用途 | 使用入口 |
|---|---|---|
| 文本（text） | 对话、问答、工作流生成 | 各处模型选择器 |
| 视觉（vision，多模态） | 在文本能力基础上支持上传图片识别 | 对话输入栏出现上传图片按钮 |
| 文生图（image） | 文本生成图片 | 绘画页 |
| 语音合成（tts） | AI 回复转语音 | 角色[语音设置](../chat/character-config.md) |
| 语音识别（asr） | 语音提问转文字 | 对话输入栏话筒图标 |

## 能力差异

不同模型支持的能力不同，界面会按模型自动适配：

- **深度思考**：
  - 模型不支持时，开关禁用并提示「模型不支持深度思考功能」；
  - 模型不支持**关闭**时（如 deepseek-reasoner），提示「模型不支持关闭深度思考功能」，开关保持开启；
- **联网搜索**：模型不支持时提示「模型不支持联网搜索功能」；
- **互斥关系**：DeepSeek 的深度思考与工具 / 联网搜索互斥，同时开启会自动关闭其一并提示；
- **图片识别**：仅视觉模型显示上传图片入口（PNG / JPG，≤ 4MB；不支持时提示「模型不支持图片识别」）。

## 模型不可用时

- 模型选择器中带**红点**的模型为健康检查未通过：悬浮显示具体原因（healthReason）或「Unavailable」；
- 选择可用模型即可；模型的启用与平台配置属于管理端工作，见[管理端使用](../admin/admin.md#模型平台与模型管理)；为系统接入新平台的开发流程见[新模型平台接入指南](../../dev/model-platform-integration.md)。

> [!TIP]
> 同一功能换一个模型结果差异可能很大：推理类问题优先选推理（reasoner）模型；日常对话用普通文本模型更省额度。免费 / 付费标记影响你的[额度](../account/usage.md)结算口径。
