# 额度与用量

> [← 使用指南](../index.md) · [English](../../../en/guide/account/usage.md)

在**设置 → 额度**页签查看你的资源消耗。数据按**付费模型 / 免费模型**两个页签分组，各含两类卡片。

## 文本聊天

| 指标 | 说明 |
|---|---|
| 今日请求数 | 当天的对话 / 问答请求次数 |
| 今日消耗 token 数 | 当天输入 + 输出的 Token 总量 |
| 本月请求数 | 本月累计请求次数 |
| 本月消耗 token 数 | 本月累计 Token 消耗 |

带「/ 上限」后缀的指标受配额限制（如「128 / 1000」），达到上限后当日 / 当月无法继续使用相应能力。

## 图片生成

| 指标 | 说明 |
|---|---|
| 今日绘图数量 | 当天生成的图片张数 |
| 本月绘图数量 | 本月生成张数 |

## 说明

- 免费模型的消耗通常单独限额；付费模型消耗对应平台的 Token 用量——同一操作选免费模型可减轻额度压力；
- 配额由管理员在管理端按**四个维度**——Token 消耗、请求次数、图片生成、聊天提问——各设每日与每月上限（见[管理端使用](../admin/admin.md#额度配置)）；显示「Token 额度无限」表示未设上限；
- 除额度外还有**限流**（时间窗口内请求数上限），触发时会提示稍后再试；
- 超出额度时对应功能受限，可联系管理员调整。
