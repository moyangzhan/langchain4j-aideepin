# 服务与工具（MCP）

> [← 使用指南](../index.md) · [English](../../../en/guide/mcp/mcp.md)

MCP（Model Context Protocol）是一种标准化的外部工具接入协议。管理员在系统中登记 MCP 服务后，用户按需**启用并配置参数**，即可让 AI 在对话中调用这些工具（联网搜索、数据库查询、第三方 API 等）。

左侧菜单**工具**进入工具页，顶部两个视图：

| 视图 | 内容 |
|---|---|
| 服务与工具 | 系统内全部可用服务 |
| 我的工具 | 你已配置的服务 |

> 用户不能自建 MCP 服务，只能使用管理员预置的服务；服务列表分页加载。

## 查看与配置服务

1. 在「服务与工具」中点击服务卡片上的**详情**，阅读 Markdown 介绍与「相关网址」；
2. 点击**配置**（未配置过的显示**启用**）打开配置弹窗：
   - **介绍**页签：服务说明；
   - **配置**页签：服务参数表（参数 / 值 / 是否敏感信息——敏感信息会**加密存储**）；无需参数的服务会提示「该服务无需配置参数即可使用」；
3. 填写参数，**状态**选择**启用**（暂存 = 仅保存不生效），点击确定，提示「保存配置成功」。

## 在对话中使用

工具需要在**角色**中勾选才会被调用：

- 在[角色进阶设置](../chat/character-config.md#服务与工具mcp)的「服务与工具(MCP)」中勾选；
- 或在对话输入栏点击**工具**标签即时勾选。

配置好后，AI 会在需要时自动调用相应工具。注意 DeepSeek 模型的深度思考与工具调用互斥。

## API

顶栏更多菜单 **API** 可生成工具类 API Key，通过 `/ext/v1/mcp` 接口拉取服务清单，详见 [API 参考 · MCP 服务](../../api/mcp.md)。
