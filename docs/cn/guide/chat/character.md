# 角色管理与预设角色

> [← 使用指南](../index.md) · [English](../../../en/guide/chat/character.md)

在 AIDeepIn 中，**会话即角色**：每个角色有独立的设定、关联资源与对话历史。左侧角色列表点击即切换会话，悬浮在角色上会出现**编辑**铅笔图标。

> [!NOTE]
> 每个账号最多创建 50 个角色（含从预设复制的）。达到上限时新建按钮会提示「最多只支持50个角色」，可删除不再使用的角色腾出名额。

## 新建角色

1. 点击角色列表上方的**新建角色**按钮。
2. 弹窗含两个页签：**新建角色**与**预设角色**；停留在**新建角色**页签。
3. 填写角色表单（各字段说明见[角色进阶设置](character-config.md)），至少填写**名称**。
4. 点击保存，新角色出现在角色列表顶部。

## 从预设角色创建

预设角色是系统内置的现成角色库，按场景分为 11 类：技术/工程、内容/创意、教育/学术、商业/管理、专业服务、设计/图像、市场营销、客服/支持、行政/办公、汇报助手、其他。

1. 点击**新建角色**，切换到**预设角色**页签。
2. 展开感兴趣的分类，浏览条目。
3. 点击条目展开查看**角色设定**详情，判断是否合用。
4. 点击**使用**，系统将该预设复制为你的角色，提示「创建成功」。
5. 已使用过的预设会标记**已使用**；再次点击**使用**会直接切换到当初复制出的那个角色，不会重复创建。

> [!TIP]
> 带**含知识库**标签的预设角色，复制时会自动为你创建一个同名的专用知识库（提示「知识库「{kbTitle}」已创建」），开箱即具备该领域的问答能力，无需手动建库导文档。

## 编辑与删除角色

**编辑**：

1. 悬浮角色列表条目，点击铅笔图标（或对话顶栏 更多 → 编辑）；
2. 修改表单后点击底部**保存**。

**删除**：

1. 打开角色编辑表单；
2. 点击底部**删除**按钮；
3. 二次确认「确定删除 {角色名} 角色？」后删除。

> [!WARNING]
> 删除角色会**连同其全部对话历史**一起移除，且不可恢复。
