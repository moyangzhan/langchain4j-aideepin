# 角色管理与预设角色

> [← 使用指南](../index.md) · [English](../../../en/guide/chat/character.md)

在 AIDeepIn 中，**会话即角色**：每个角色有独立的设定、关联资源与对话历史。左侧角色列表点击即切换会话，悬浮在角色上会出现**编辑**铅笔图标。

> 每个账号最多创建 50 个角色。

## 新建角色

点击角色列表上方的**新建角色**按钮，弹窗含两个页签：**新建角色**与**预设角色**。

在**新建角色**页签中填写角色表单（字段说明见[角色进阶设置](character-config.md)），保存后即出现在角色列表中。

## 从预设角色创建

**预设角色**页签提供了按场景分类的现成角色，分类包括：技术/工程、内容/创意、教育/学术、商业/管理、专业服务、设计/图像、市场营销、客服/支持、行政/办公、汇报助手、其他。

使用方式：

1. 展开分类，查看条目的**角色设定**详情；
2. 点击**使用**，系统将该预设复制为你的角色，提示「创建成功」；
3. 已使用过的预设会标记**已使用**，可再次使用。

> 带**含知识库**标签的预设角色，复制时会自动为你创建一个同名的专用知识库，无需手动建库。

## 编辑与删除角色

- 悬浮角色列表条目，点击铅笔图标进入编辑表单；
- 编辑表单底部的**删除**按钮可删除角色，需二次确认「确定删除 {角色名} 角色？」，删除后对话历史一并移除。
