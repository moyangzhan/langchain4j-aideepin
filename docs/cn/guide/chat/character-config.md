# 角色进阶设置

> [← 使用指南](../index.md) · [English](../../../en/guide/chat/character-config.md)

角色编辑表单（新建与编辑共用）除基础信息外，还支持关联知识库、MCP 工具与语音行为。

## 基础信息

| 字段 | 说明 | 示例 |
|---|---|---|
| 名称 | 角色名 | 李白 |
| 备注 | 给自己看的备注 | 多年写诗经验 |
| 角色设定 | 系统提示词，决定 AI 的人设与行为 | 你是唐朝的李白，用诗意的方式回答问题 |

## 深度思考

设置该角色的深度思考默认开关。部分模型（如 deepseek-reasoner）不支持关闭深度思考；不支持深度思考的模型会忽略该设置。

## 关联知识库

- 标签形式展示已关联的知识库，可逐个移除；
- 点击**添加更多知识库**打开选择器：按标题搜索，表格列出**标题 / 描述 / 属性**（我的或创建者名、公开或私有）；
- 保存后，与该角色对话时 AI 会先检索知识库再作答，回答下方可查看[引用](window.md#记忆与引用)。

知识库的创建与导入见[知识库](../knowledge-base/overview.md)一章。

## 服务与工具（MCP）

以复选框方式勾选当前角色可调用的 MCP 工具。点击**去启用更多 AI 工具**可跳转工具页配置，详见[服务与工具](../mcp/mcp.md)。

## AI 回复内容格式

| 选项 | 行为 |
|---|---|
| 自动 | 跟随你的输入格式：文字提问回文字，语音提问回语音 |
| 文字 | 始终以文字回复 |
| 语音 | 始终以语音回复 |

配套选项：

- **自动播放 AI 的回复语音**：回答到达后自动播放音频；
- **音色选择**：使用服务端 TTS 时从此处列出的音色中选择；若系统配置为浏览器端合成，则显示「当前音色来自于浏览器，无需指定」。

语音功能的完整说明见[语音输入与播报](voice.md)。

## 保存与删除

- 底部**保存**按钮提交修改；
- **删除**按钮删除角色（二次确认）。
