# 对话界面

> [← 使用指南](../index.md) · [English](../../../en/guide/chat/window.md)

对话界面分为三块：左侧**角色列表**、中间**消息区**、底部**输入区**。每个角色拥有独立的对话历史，切换角色即切换会话。

## 发送消息与流式回答

1. 在输入框输入问题，回车或点击发送。
2. 回答流式输出。发送后到回答完成前，消息区会依次显示状态提示：**问题分析中 → 知识库搜索中（关联了知识库时）→ 推理中 → 回答中**。
3. 生成过程中可点击**停止请求**中断。

消息区底部提供**滚动到底部**按钮，方便在长对话中快速回到底部。

### 深度思考

- 打开输入栏的**深度思考**开关后，回答会先展示思考过程，再给出最终答案。
- 部分模型（如 deepseek-reasoner）始终开启深度思考且不可关闭；也有些模型不支持深度思考，开关会禁用并给出提示。
- 角色级也可以设置默认的深度思考开关，见[角色进阶设置](character-config.md)。

### 联网搜索

打开**联网搜索**开关后，回答会参考搜索引擎的结果。注意：DeepSeek 模型的深度思考与工具/联网搜索互斥，同时开启时会自动关闭并提示。

### 多答案对比

对同一问题重新生成回答后，多个回答会以「回答 1 / 回答 2 …」页签并列展示，方便对比择优。

## 消息操作

- **复制 / 复制代码**：复制回答文本或其中的代码块。
- **删除消息**：删除问题会同时删除对应的回答，需二次确认。
- **重新生成**：对问题重新发起回答。

## 上传图片（图像识别）

- 仅**视觉（多模态）模型**支持上传图片，选择纯文本模型时该按钮不可用。
- 支持 PNG / JPG 格式，单张不超过 4MB。
- 上传后随问题一并发送，AI 将识别图片内容并作答。

## 输入栏的知识库与工具标签

- **知识库**：点击标签可在弹窗中即时调整当前角色绑定的知识库，无需进入角色编辑。
- **工具**：点击标签可即时配置当前角色可用的 MCP 工具。

两处修改只影响当前角色，与[角色进阶设置](character-config.md)中的配置等价。

## 上下文模式

输入栏的**上下文模式**图标决定发送时是否携带历史消息：

- 携带（默认）：多轮对话，AI 记得前文；
- 不携带：每次提问独立，不消耗历史上下文。

## 记忆与引用

每条回答下方有三个按钮，用于回答溯源：

| 按钮 | 内容 |
|---|---|
| 记忆 | 展示本次回答命中的长期记忆，按**语义记忆** / **情景记忆**分组 |
| 引用 | 展示命中的知识库片段。按文档分段模式展示：问答模式显示命中的问题与答案；父子分段模式显示命中的子块及其父段；通用分段显示段文本 |
| 图谱 | 展示本次回答参考的知识图谱片段 |

## 顶栏更多操作

- **编辑**：打开当前角色的编辑表单。
- **API**：查看 / 管理该角色的开放 API Key 与接口文档，详见 [API 参考 · 角色对话](../../api/character.md)。
