# 语音输入与播报

> [← 使用指南](../index.md) · [English](../../../en/guide/chat/voice.md)

对话支持完整的语音闭环：**语音提问**（录音 → 自动转文字发送）与**语音回答**（TTS 播报）。

## 语音输入（录音提问）

1. 点击输入栏的话筒图标**开始对话**，界面显示「对话中（N 秒）」；
2. 结束时再次点击图标，录音自动结束并**发送**；
3. 录音上传后由系统的语音识别（ASR）服务转为文字，作为提问发给 AI。

说明：

- 语音识别服务由系统管理员全局配置（同一时间只有一个 ASR 服务生效），用户无需也无法自行切换；
- 可识别的时长与文件大小上限由系统配置决定，超时录音会自动截断。

## 语音播报（AI 回复）

在角色的[进阶设置](character-config.md)中控制：

| 设置 | 说明 |
|---|---|
| AI 回复内容格式 | 自动 / 文字 / 语音——「自动」表示跟随你的输入格式 |
| 自动播放回复语音 | 回答到达后自动播放 |
| 音色选择 | 服务端 TTS 时可选音色；浏览器端合成则无需指定 |

收到语音回答后，可点击**显示文字 / 显示音频**在文本与音频两种展示间切换。

> TTS 服务同样由管理员全局配置。合成发生在服务端还是浏览器端取决于部署配置：浏览器端合成无需选择音色。

## 给开发者

为系统接入新的 ASR / TTS 平台属于开发工作，见开发文档中的[语音识别（ASR）能力接入](../../dev/capability-asr.md)与[语音合成（TTS）能力接入](../../dev/capability-tts.md)。
