# 快速开始

> [← 使用指南](index.md) · [English](../../en/guide/quick-start.md)

本页带你用最短路径完成：**注册激活 → 熟悉界面 → 首次对话**。模型平台由管理员预先配置好，普通用户开箱即可使用。

## 1. 注册与激活

1. 打开 AIDeepIn 站点，点击左下角**登录**按钮，在弹窗中切换到**注册**页签。
2. 填写邮箱、密码（不少于 6 位）、确认密码，输入图形验证码（看不清可点击图片刷新）。
3. 提交后系统会向你的邮箱发送一封激活邮件，请查收（若未收到，请检查垃圾箱）。
4. 点击邮件中的激活链接，浏览器跳转到激活结果页；显示**激活成功**后，5 秒内自动返回首页。

激活成功后即可使用邮箱和密码登录。详细说明（忘记密码、修改密码等）见[注册、登录与账户设置](account/account.md)。

## 2. 熟悉界面

登录后，屏幕最左侧是全局菜单（仅图标，悬浮显示文字），从上到下依次为：

| 菜单 | 功能 |
|---|---|
| 聊天 | 与 AI 角色对话 |
| 绘画 | 文本生成图片 |
| 画廊 | 浏览公开图片、查看我的点赞 |
| 知识库 | 基于知识库的问答 |
| 应用 | 创建与运行工作流 |
| 工具 | 启用 MCP 扩展工具 |

左下角还有三个入口：**提示词商店**、**设置**（主题、语言、额度、修改密码）与**退出登录**。

## 3. 首次对话

1. 点击**聊天**进入对话界面。新账号会自动创建一个默认角色。
2. 在底部输入框上方的模型选择器中挑选一个模型：
   - 列表中的模型由管理员配置，显示为「平台头像 + 模型名」；
   - 若模型显示为不可用（置灰），说明该模型当前异常，换一个即可；
   - 模型选择**全局生效**，切换后绘画、知识库问答等处同步变化。
3. 在输入框输入问题，回车或点击发送按钮。
4. 回答以流式方式逐步输出。期间可随时点击**停止**中断生成。

### 试试这些进阶玩法

- **深度思考**：打开输入栏的深度思考开关，回答前会先展示思考过程（部分推理模型不支持关闭）。
- **联网搜索**：打开后回答会参考搜索结果。
- **上传图片**：选择视觉（多模态）模型后，可上传 PNG / JPG 图片（≤ 4MB）让 AI 识别内容。
- **换个角色**：在左侧角色列表上方点击**新建角色**，或从 11 类**预设角色**中一键创建。
- **语音对话**：点击输入栏的话筒图标开始录音，松开后自动转文字发送。
